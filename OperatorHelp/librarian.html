Подключение к GitHub

Токен хранится только в этом браузере (localStorage) и никогда не попадает в код страницы или в репозиторий. На новом устройстве введите его заново. Нужен fine-grained personal access token с правом Contents: Read and write только для репозитория с данными.

Без токена доступны разбор и предпросмотр страницы и скачивание файла, запись в репозиторий нет.

Страница документации

Получить HTML можно в DevTools: откройте страницу, нажмите F12, найдите элемент data-testid="content", правый клик, Copy, Copy outerHTML.
