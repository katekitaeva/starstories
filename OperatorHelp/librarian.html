Подключение к GitHub

Токен хранится только в этом браузере (localStorage) и никогда не попадает в код страницы или в репозиторий. На новом устройстве введите его заново. Нужен fine-grained personal access token с правом Contents: Read and write только для репозитория с данными.

Без токена можно проверить страницу и скачать файл, а отправка в репозиторий и работа с кэшем недоступны.

Перенос страниц с портала в кеш

Откройте страницу документа на портале и нажмите F12. Найдите самый верхний тег страницы (обычно это <div data-role="content">), нажмите на нём правой кнопкой мыши, выберите Copy, затем Copy outerHTML, и вставьте скопированное в поле «Тело документа в HTML». После отправки документ появится в библиотеке через пару минут.
